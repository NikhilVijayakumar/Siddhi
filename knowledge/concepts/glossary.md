# Portfolio and evidence glossary

| Term | Meaning |
|---|---|
| Portfolio | Goals and investments considered together so shared dependencies and competing outcomes remain visible |
| Goal | A desired result and reason for investing attention; can precede a project |
| Intended outcome | A specific result sought by a goal, assessed by relevant criteria |
| Observed result | What attributable evidence indicates occurred, not what was planned |
| Initiative | Coordinated work contributing to one or more goals |
| Project reference | A stable local reference to an externally inventoried project |
| Priority | An owner-controlled preference with rationale and historical context |
| Constraint | A declared limitation shaping choices |
| Assumption | A planning proposition not yet established as fact |
| Plan | A proposed approach for a supported portfolio scope |
| Plan revision | A particular version whose approval is independent of its creation |
| Milestone | An assessable checkpoint; completion declarations and verification are separate |
| Dependency | A typed, directed prerequisite with rationale and confirmation context |
| Review | A bounded examination retaining the reports, evidence, and plan revisions considered |
| Source artifact | An identifiable record from an external system |
| Snapshot | A time-bounded observation of a defined source scope, with capture outcome |
| Normalized record | A versioned transformation of a source observation, not a new source authority |
| Evidence | An attributable observation relevant to a portfolio question |
| Assessment | Interpretation of evidence against an applicable criterion |
| Criterion | A purpose-specific definition of what evidence counts and how it is evaluated |
| Finding | An analytical conclusion with inputs, explanation, method, and limitations |
| Certainty | Strength of support for an interpretation, including ambiguity |
| Sufficiency | Adequacy of applicable evidence to answer a particular criterion |
| Freshness | Observation recency and applicability to the requested point in time |
| Coverage | Source scope actually inspected successfully, including exclusions |
| Verification | A recorded checking process applying to a stated scope and revision |
| Execution state | Whether an operation or intended action actually ran and its outcome |
| Recommendation | A proposed action, not approval or proof of execution |
| Decision | An explicit choice by an authorized decision-maker, with rationale |
| Provenance | Traceable identity, revision, observation, transformation, and reasoning context |
| Archival | Removal from active work without automatic loss of historical references |

# Non-equivalences

Discovery is not accessibility; accessibility is not complete coverage; parsing
is not verification. Verification does not automatically establish goal achievement.
Freshness is not certainty. Relevance is not sufficiency. Approval is not execution.
A new revision is not necessarily the active approved revision. Missing evidence
is not evidence of failure. Source identity is not its mutable name or locator.

Definitions express proposed shared vocabulary and established direction, not
final lifecycle enumerations or a record of human verification.

See [portfolio domain](portfolio-domain.md) and [evidence semantics](evidence-semantics.md)
for context and unresolved modeling choices.
