These are retained **historical, unreconciled, non-authoritative mixed drafts**,
not approved requirement packages or a second maintained architecture. Do not
edit them to implement features or interpret their acceptance labels as approval.
Their old relative links, document names, route proposals, and contradictions are
preserved as historical input, not a maintained navigation surface.

Use the [requirements guide](../README.md) for behavioral ownership and the
[knowledge index](../../../knowledge/index.md) for reusable concepts.

## Preservation

All 22 Product/Architecture/Integration/API draft bodies are retained here. The
[migration report](../../documentation-migration.md) links source maps and SHA-256
inventories. Seventeen files are byte-exact. Five API files have only surplus EOF
newline bytes; the API migration register records original/current hashes and the
exact in-memory normalization that reconstructs their original bytes. No substantive
source text is missing. This difference is disclosed, not claimed as byte equality.

The [original documentation proposal](../../document.md) is historical planning
context, not an instruction to bypass reviewed requirement packages.
